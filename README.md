# Harmonia - Music Learning Platform

A responsive music-themed front-end website developed with HTML5, CSS3, and Bootstrap 5.

This project was developed as part of my front-end learning process. I customized the visual concept, music-focused content, colors, and imagery while practicing responsive web design and Bootstrap components.

## 🚀 Technologies

* HTML5
* CSS3
* Bootstrap 5.3.7
* Bootstrap Icons
* Google Fonts (Nunito)

## ✨ Features

* Responsive navigation bar
* Bootstrap carousel
* Music-themed hero section
* About section
* Course cards and course categories
* Instructor section
* Responsive grid layout
* Footer and contact sections
* Bootstrap icons and utility classes
